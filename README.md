# 📊 Finance Summary Dashboard – Excel

An interactive **Excel-based Finance Dashboard** designed to analyze and visualize financial performance using KPIs, Pivot Tables, and dynamic filters.  
This project focuses on **reporting, analysis, and decision support**, similar to real-world finance and operations environments.

---

## 🚀 Features

- 📈 **KPI Cards**
  - Total Revenue  
  - Total Expense  
  - Profit & Loss  
  - Max Revenue  
  - Max Expense  

- 📊 **Visual Analysis**
  - Revenue vs Expense by Department  
  - Profit Trend by Month  
  - Revenue by Category  
  - Expense by Category  

- 🎛 **Interactive Filters (Slicers)**
  - Year  
  - Month  
  - Quarter  
  - Department  
  - Payment Method
